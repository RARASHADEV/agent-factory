# Domain-config loader and validator (domains/*.yaml)

## Objective
Load and validate domain configs (`orchestration/domains/*.yaml`) that define a supervisor, roster, and policy — the data that parameterizes the generic engine.

## Context
Epic AF-41. Spec: `docs/tech-design-orchestration.md` §4.2 (Domain Config schema). Data-only; no orchestration logic here. Validation must be strict (fail loud, §6.1).

## Acceptance
- [ ] Parses `domain`, `supervisor.agent`, `roster[]`, `policy{}` from YAML
- [ ] Validates: supervisor + every roster slug resolve to a real `agents/*.md`; `required_finalizers` ⊆ roster; `parallelizable` ⊆ roster
- [ ] Throws a clear error on any invalid/missing field (no silent defaults for required fields)
- [ ] Unit tests cover valid + each invalid case
