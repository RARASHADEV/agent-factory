# Pipeline Flow 6: Pipeline status command — af pipeline status

## Objective

Build the `af pipeline status` command that shows the current state of pipeline executions — which phase is running, which passed, which failed, and what's next. Provides observability into autonomous pipeline runs.

## Context

Part of the Pipeline series (AF-23 → AF-28). Depends on AF-26 (pipeline runner writes `pipeline-state.json`).

When a pipeline runs autonomously (potentially for 30+ minutes across multiple agent spawns), the user needs a way to check progress without reading raw log files. This is the equivalent of `af agent status` but for pipelines.

## Solution

1. **Create `pipelineStatusCommand()`** in `src/commands/pipeline.ts`:
   - `af pipeline status [ticket]` — show status for a specific ticket's pipeline run, or all active runs
   - Reads `pipeline-state.json` from `.af/output/{ticket}/`
   - Displays:
     - Pipeline name and ticket
     - Overall status (running, completed, failed, paused)
     - Phase-by-phase breakdown with status icons (✅ ⏳ ❌ ⏸️)
     - Current phase + agent + duration so far
     - Gate results for completed phases
     - For failed phases: the gate failure message
   - Optional `--json` flag for machine-readable output

2. **Create `pipelineListCommand()`** — `af pipeline list` shows available pipeline definitions (from `.af/pipelines/`).

3. **Register in CLI** — `af pipeline status [ticket]` and `af pipeline list` subcommands.

4. **Example output:**
   ```
   Pipeline: sdlc — AF-30
   Status: running (12m 34s)

     ✅  design      architect     completed  (3m 12s)   gate: PASS
     ⏳  implement   engineer      running    (9m 22s)
     ⏸️  verify      qa            pending
     ⏸️  release     deploymanager pending

   Output: .af/output/AF-30/
   ```

## Acceptance
- [ ] `af pipeline status AF-30` shows phase-by-phase breakdown of a pipeline run
- [ ] `af pipeline status` (no ticket) shows all active/recent pipeline runs
- [ ] Each phase shows: status icon, name, agent, duration, gate result
- [ ] Failed phases show the gate failure message
- [ ] `af pipeline list` shows available pipeline definitions with descriptions
- [ ] `--json` flag outputs machine-readable format
- [ ] Works correctly for running, completed, and failed pipelines
