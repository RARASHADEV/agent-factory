# AF CLI: local backend routing + execution frontmatter (Ollama/vLLM)

## Objective
Add a `local` execution backend to AF CLI and route per the agent's `execution` frontmatter, so an agent can run on Ollama/vLLM instead of the Claude SDK.

## Context
Epic AF-41. Spec: `docs/tech-design-orchestration.md` §4.1 (frontmatter schema), §6.2 (local-model tool-calling). Model routing lives **here** (one place); layers above are model-agnostic. New frontmatter block: `execution.{backend, model, endpoint, toolCalling}`, default `backend: claude` (back-compat).

## Acceptance
- [x] `execution` frontmatter parsed; absent block defaults to Claude (no behavior change for existing agents)
- [x] `backend: local` dispatches to an Ollama/vLLM endpoint and returns output
- [x] `toolCalling: prompt` path implemented for local models (prompt-based protocol / structured-output parsing)
- [x] Backend reports normalized `TokenUsage` (input/output) — see AF-45
- [x] `endpoint` validated against an allow-list (SSRF guard, §8)
