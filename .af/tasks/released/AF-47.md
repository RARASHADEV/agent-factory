# Agent editor UI: Execution panel (backend/model/endpoint/toolCalling)

## Objective
Add an Execution panel to the agent editor so users configure an agent's backend/model/endpoint/toolCalling from the UI, written back into `execution` frontmatter via the existing save path.

## Context
Epic AF-41. Spec: `docs/tech-design-orchestration.md` §5.3. Reuse existing flow — `GET /api/agents/[slug]` returns parsed frontmatter; `saveAgent(slug, content)` writes back. **No new sync** (UI and CLI share `agents/*.md`). Depends on the frontmatter schema from AF-42.

## Acceptance
- [ ] Execution panel: backend dropdown (`claude|local`), model field, endpoint, toolCalling toggle
- [ ] Loads existing `execution` values; saving serializes the block into frontmatter via `saveAgent`
- [ ] Endpoint input validated (no arbitrary URLs — align with AF-42 allow-list)
- [ ] Behind existing auth (`web/src/lib/auth.ts`)
- [ ] (Stretch) read-only Domains view listing supervisor + roster per domain
