# Generic agent orchestration module

## Objective
Build a domain-agnostic orchestration module: a supervisor agent (Campaign Director, Team Lead, …) decomposes an objective and delegates to a roster of AF agents, with per-agent execution backend (Claude SDK vs. local Ollama/vLLM) configurable from the Agent Factory UI.

## Context
Full spec: `docs/tech-design-orchestration.md`. Four layers: **Orchestrator → Executor → AF CLI → {Claude SDK | Ollama/vLLM}**. New domain = config file + agent `.md` defs, no engine changes. Supervisor mode = **constrained-dynamic** (Option B) with guardrails.

Children: AF-42 (CLI local routing), AF-43 (domain loader), AF-44 (UI dir/synced chore), AF-45 (Executor), AF-46 (Orchestrator engine), AF-47 (UI Execution panel).

## Acceptance
