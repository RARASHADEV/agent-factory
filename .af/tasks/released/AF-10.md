# Cross-project CLI view — af status --all

## Objective

Add an `af status --all` command that shows task status across all AF-enabled projects, not just the current directory's project.

## Context

Brahma works across multiple projects (oracle-bridge, agent-factory, astra, loka, linkedin, timetracker). Currently `af status` only shows the current project. A cross-project view lets Ora and Brahma see the full picture without cd-ing into each project.

## Acceptance
- [x] `af status --all` scans known project directories for `.af/tasks/`
- [x] Shows aggregated view: project name, open/in-progress/done counts, blocked items
- [x] Project registry in `~/.af/projects.json` or auto-discovery from `~/projects/*/`
- [x] Output is clean and scannable (table format)
- [x] Works when run from any directory
